# Soapbox for Ferdium

[Soapbox](https://docs.soapbox.pub/soapbox/) is an alternative frontend for Mastodon and Pleroma that focuses on customization and ease of use.

[Nicolium](https://nicolium.app/) is a fork of Soapbox that adds many additional features and quality-of-life improvements.

To use this recipe, enter the URL of your instance's Soapbox/Nicolium installation in the field "Custom server". 

You can also use one of the public, universal instances (https://fe.soapbox.pub for Soapbox and https://web.nicolium.app for Nicolium) with ANY Mastodon-compatible Fediverse instance.
In this case, you will enter your instance address in the web app istelf.

## 💡 Tip

Make sure you enable the "Use service favicon" setting (under Appearance), so Ferdium will display your instance's logo instead of the generic default. Alternatively, you can always upload a custom icon.
